# overview
- OSI标准化跨平台的语义元数据交换工作，具有厂商中立的特征。
- OSI内的模块有
  1. Semantic Model: 数据集 关系 指标
  2. Datasets: 逻辑业务实体，事实表维度表。
  3. Fields: group, filter, metric表达式
  4. Metrics
  5. Dimensions
  6. Relations
